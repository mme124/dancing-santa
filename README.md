# dancing-santa

노래를 들려주면 산타가 박자와 곡의 분위기에 맞춰 춤추는 프로그램을 만든다.

## 첫 데모

`index.html`을 WebGL을 지원하는 브라우저에서 열고 템포(80, 110, 140 BPM)를 고른 뒤 **재생**을 누른다. 내장 4박자 리듬에 맞춰 3D 산타가 몸을 흔들고 팔과 다리를 움직인다. **보기 각도** 슬라이더로 산타를 한 바퀴 돌려 볼 수 있다. **정지**를 누르면 리듬이 멈추고 산타가 기본 자세로 돌아온다. 설치나 인터넷 연결은 필요 없다.

리듬과 동작은 같은 오디오 시계를 사용한다. **내장 리듬 재생** 버튼은 선택한 템포로 내장 리듬과 춤을 재생한다.

## 음악 넣기

**음악 넣기**에서 음악 파일을 선택하고, 파일 이름 아래에 나타나는 플레이어에서 재생한다. 플레이어에서 일시정지, 곡 이동, 음량 조절을 할 수 있다. 다른 파일을 선택하면 이전 곡이 멈추고 새 곡이 준비된다. 음악과 내장 리듬은 번갈아 재생한다. 지원하는 음악 형식은 사용하는 브라우저에 따라 달라진다.

## 노래 분위기 분석

**음악 넣기**에서 30 MiB 이하의 음악 파일을 고르면 브라우저가 파일을 읽고 **차분함**, **경쾌함**, **활기참** 중 하나를 표시한다. 파일은 브라우저 안에서 처리한다. 30 MiB를 넘는 파일도 플레이어에서 재생할 수 있다.

곡을 20 ms씩 나눠 음량을 구하고, 곡 자체의 음량을 기준으로 소리가 갑자기 커진 구간을 강세 후보로 센다. 결과에는 초당 강세 횟수와 강세에서 음량이 평균적으로 얼마나 올랐는지 함께 표시한다. 강세가 자주 나오고 변화가 클수록 더 활기찬 춤에 맞는 곡으로 분류한다. 분류 기준은 실제 곡에 맞춰 조정할 초기값이다.

현재 분류는 곡 전체의 리듬 활동량을 요약한다. 길게 이어지는 강한 소리나 곡 중간의 분위기 변화는 이 방식으로 놓칠 수 있다. 분석 결과는 화면에 표시되며, 음악 파일의 박자를 찾아 산타 동작에 연결하는 작업은 다음 단계다. [강세 검출 방식 참고](https://ieeexplore.ieee.org/document/1495485/)

## 진행 순서

1. **리듬에 맞춰 움직이기** — 내장 리듬과 산타의 움직임을 맞춘다. 첫 데모에 구현했다.
2. **내 노래로 춤추기** — 음악 파일을 열고 재생할 수 있게 한다. 곡에서 박자가 찍히는 시점을 찾아 그 시점에 산타가 움직이도록 연결한다.
3. **분위기에 따라 춤 바꾸기** — 리듬의 강세로 곡의 춤 강도를 추정하는 기능을 추가했다. 실제 곡에 맞춰 기준을 다듬고, 같은 BPM에서도 추정 결과에 따라 다른 춤을 적용한다.
4. **산타 모델과 모션 다듬기** — 첫 데모에 적용한 3D 산타의 외형과 관절 움직임을 다듬고, 곡에 맞는 춤 동작을 늘린다.

다음 작업은 음악 파일 한 곡을 불러와 재생하고, 곡에서 찾은 박자에 맞춰 기존 산타를 움직이는 것이다.

## 관절 제어와 프레임 데이터

`joint-demo.html`을 열거나 음악 데모의 **산타 관절 테스트 열기**를 누른다. 어깨·팔꿈치·고관절·무릎·몸통·머리를 골라 슬라이더로 조절한다. 팔꿈치와 무릎은 X축 굽힘을 사용한다. **프레임 데이터 재생**은 30 fps, 90프레임의 예시 포즈를 반복한다. 화면 아래에는 보정 후 적용된 프레임의 JSON이 표시된다.

`createSantaStage(canvas)`는 기존처럼 호출 가능한 렌더 함수를 반환한다. 기존 `draw(sway, bounce, turn)`과 새 `draw.drawPose(pose, turn)`을 모두 사용할 수 있다.

```js
const draw = createSantaStage(document.querySelector('canvas'));

// 기존 춤 호출
draw(0.5, 0.8, 0);

// 외부 모델이 만든 한 프레임의 포즈
draw.drawPose({
  root: {
    position: { x: 0, y: 0.05, z: 0 },
    rotation: { x: 0, y: 0.2, z: 0 },
  },
  joints: {
    leftArm:  { x: 0.3, y: 0, z: 0.6 },
    rightArm: { x: 0, y: 0, z: -0.6 },
    leftLeg:  { x: -0.2, y: 0, z: 0 },
    rightLeg: { x: 0, y: 0, z: 0 },
    leftElbow:  { x: -1.0 },
    rightElbow: { x: -0.5 },
    leftKnee:   { x: 0.7 },
    rightKnee:  { x: 0 },
    torso:    { x: 0, y: 0.1, z: 0 },
    head:     { x: 0, y: -0.2, z: 0 },
  },
}, 0);

// 기존 춤 위에 머리 동작 추가
const pose = createSantaDancePose(0.5, 0.8);
pose.joints.head = { y: 0.3 };
draw.drawPose(pose, 0);
```

회전은 라디안 단위이며, 관절의 기본 자세에 더해지는 회전값이다. 생략한 관절과 축은 매 호출마다 0으로 요청되며, 어깨와 팔꿈치에는 몸통 관통 방지 보정이 적용될 수 있다. `draw.drawPose()`는 실제 적용한 포즈 객체를 반환한다. `root.position`은 모델 좌표 단위의 이동이다. X는 화면 오른쪽, Y는 위쪽, Z는 산타 정면 방향인 좌표계에서 시작한다. 왼팔·왼다리는 산타 기준 왼쪽으로, 정면에서 보면 화면 오른쪽에 있다.

각 회전 행렬은 `Ry * Rz * Rx`로 합성한다. 열벡터에 X, Z, Y 순서로 적용하며, 양의 회전은 오른손 법칙을 따른다. `turn`은 기존과 같이 모델 전체의 Y 회전에 더하는 라디안 값이다. 외부 모델의 좌표축·각도 단위·회전 순서를 이 규약에 맞춰 변환해 입력한다.

양팔은 어깨, 양다리는 골반의 각 다리 연결점, 머리는 목을 기준으로 회전한다. 팔꿈치는 전완과 장갑, 무릎은 종아리와 신발을 움직인다. 몸통은 골반 높이를 기준으로 회전하며 머리와 팔이 함께 따라간다. 다리는 전체 `root` 변환을 따른다.

`leftElbow`·`rightElbow`는 X축 -135°부터 0°, `leftKnee`·`rightKnee`는 X축 0°부터 135°의 경첩 관절이다. 이 네 관절의 Y·Z축은 0으로 제한한다. 어깨의 X·Y 회전을 제한하고, 상완·전완·장갑의 경계 구와 몸통 타원체 사이의 거리를 검사한다. 충돌 시 어깨를 바깥으로 벌리며, 필요한 경우 팔꿈치도 펴서 보정한다. 어깨 연결부는 옷과 자연스럽게 겹쳐 연결된다. 입력 포즈는 수정하지 않고, 반환 포즈에 보정 결과를 담는다.

생략 가능한 `root`, `root.position`, `root.rotation`, `joints`는 객체로 전달한다. 알려진 축에 문자열·NaN·Infinity 등을 넣으면 그 프레임을 그리기 전에 TypeError가 발생한다. 외부 데이터의 추가 메타데이터는 무시한다.

시간 제어는 호출자가 맡는다. 외부 AI 프레임이 `{ time: 초, pose: 위 형식 }`이면 현재 재생 시간에 해당하는 프레임을 골라 `draw.drawPose(frame.pose, turn)`을 호출한다. 예시 데모는 고정 30 fps를 사용하며, 관절 데이터 자체에는 fps를 강제하지 않는다.

회귀 검증은 `node --test santa.test.cjs`로 실행한다. 기존 춤 API와 프레임 API, 관절별 영향 범위, 입력 검증, 관절 제한, 81개 어깨·팔꿈치 조합에서 팔다리 모델 표면의 몸통 관통 여부를 검사한다.
